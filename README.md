- 目はまばたき・視線の泳ぎ・ゆらぎ。画面をなでると指を追う。タップでウインク
- 90 分を超えると半目になる
- ときどき独り言（「水、飲んだ？」など）。設定でオフ可
- 今日の合計時間は端末に保存（localStorage）
- 声かけを無視し続けると 3 分ごとにため息＋ひと言
- 60 / 120 / 180 分の節目で褒める
- 途中で閉じても 10 分以内に開けば続きから（それ以上は合計に足して終了）
- 設定: 目の明るさ、休憩に誘う時の音（既定オフ）とバイブ（Android）
- PC: Space で開始 / 休憩 / 戻る
- 黒ベタなので OLED だとほぼ消灯。眩しくない

## しぐさ

方針: 作業中は「集中系」、休憩中は「癒し系」。騒がしい動きは入れない。

**作業中（待機）** ときどきどれか。頻度は設定「しぐさの多さ」。

| しぐさ | 目 |
|---|---|
| 集中 | 少し細めて瞳が小さく中央、ほんの少し前のめり。まばたきしない（一番多い） |
| 考え事 | 斜め上を見て、雲の吹き出しに「・」「・・」「・・・」→ 瞳が小刻みに揺れる →「？」 |
| ぼーっ | 瞳が広がって視線が漂う「…」 |
| 首かしげ / キョロキョロ | たまに |
| ウトウト・目をこする・伸び・寝落ち | 深夜（〜5時）と 90 分超の時だけ |

**休憩中** 目を閉じたまま、20〜50 秒おきに。

| しぐさ | 目 |
|---|---|
| にこにこ | 笑ったままゆらゆら |
| うっとり | 半目で沈んでゆらゆら |
| 寝息 | 雲に「z z z」→「…ん」 |
| 照れ笑い / ハート目 | たまに |

**反応するもの**

| きっかけ | 目 |
|---|---|
| 「はじめる」 | 笑って一言 → やる気（内側に傾けて「…！」）。朝 5〜10 時はあくび |
| 画面をなでる | 指を追う。5 秒続けるとうっとり |
| 目をタップ | ウインク笑い。3 回連打でじとっ「くすぐったい」 |
| どこでも長押し | 「そっちに何かあるの？」と言いながら、押している間じわじわ指の方へ寄る（目の端が指から 70px より近くは行かない）。目同士も寄ってコンパクトに。指が目の上なら ^ ^。離すと戻る |
| 目の周りを指で 2 周 / 端末を振る | 瞳がぐるぐる → ×目、頭上に渦巻き |
| 別の画面から戻ってきた | にこにこ揺れて「おかえり」 |
| 8 秒未満だけ画面が隠れた（通知を見た？） | 上を見上げて「大事なものなら見たほうがいいと思うよ」 |
| 本体が短く震えた（通知のバイブ、実験的） | 同上。URL に `?debug` で数値を表示 |
| 25 分ごと | 小さくうなずく |
| 60 / 120 / 180 分 | 感心（見開いて「ほー」）＋ 褒める |
| 休憩の誘いを 3 分放置 | しょんぼり＋ひと言、3 分ごと |
| 「あと5分」を 3 回連続 | にやり「ほんとに？ …5分だけね。」 |
| 休憩から戻る | 片目ずつ開く →「ちゃんと休めた。えらい。」 |
| 「終了」 | しょんぼり「おつかれ。」 |

ほかにも候補の表情がエンジンに入っている（`src/behaviors.ts` の bodySet / smileSet）。`me.play('名前')` で再生。

確認用: URL に `?demo` を付けるとしぐさが 6〜12 秒おきになり、自動で開始する。

## 使い方（スマホ）

1. 上の URL を開く
2. 「ホーム画面に追加」すると全画面で起動
3. 「はじめる」

## バージョン

設定画面の右上に `v0.4.0` のように出る。更新が反映されたか確認するのに使う。履歴は [CHANGELOG.md](CHANGELOG.md)。

リリース手順:

```sh
npm run release -- minor "しぐさを追加"   # patch | minor | major
git push && git push --tags
```

## 開発

Vite + Preact + TypeScript。依存は Preact のみ。

```sh
npm i
npm run dev
```

| ファイル | 役割 |
|---|---|
| `src/App.tsx` | セッション状態（off / focus / break）、声かけ、Wake Lock、全画面 |
| `src/Eyes.tsx` | 目。まばたき・視線・ゆらぎ・指追い・演目の再生 |
| `src/behaviors.ts` | しぐさの定義。ポーズ（まぶた・瞳・伸縮・形・一言）の列 |
| `src/Settings.tsx` | 設定ダイアログ |
| `src/lines.ts` | セリフ集。ここに足せば口数が増える |
| `src/store.ts` | localStorage（設定・今日の合計） |
| `public/lp/` | 紹介ページ（静的 HTML。ヒーローは実アプリを iframe で縮小表示） |

## デプロイ

`main` に push → GitHub Actions が `dist` を GitHub Pages に配信。

# め

黒い画面に、目だけ。勉強や作業のとなりに置いておく相棒。
スマホを横向きにして机の端に立てかける想定。

**→ https://kotta-27.github.io/me-buddy/**

![待機中。白い目が2つ、まばたきして視線が泳ぐ](docs/03-focus.png)

## できること

| | |
|---|---|
| ![「つづき、やろう。」と笑った目](docs/02-start.png) | **はじめる**<br>計測開始。目が笑って一言。 |
| ![「5分たったよ。ひと息いれよう。」と声かけ。あと5分 / 休憩する](docs/04-nudge.png) | **声かけ**<br>一定時間（既定 50 分）で「そろそろ休憩しない？」。あと5分 / 休憩する。 |
| ![目を閉じて休憩中。もどるボタン](docs/05-break.png) | **休憩**<br>目を閉じてカウントダウン。終わると「そろそろ、もどろうか」。 |
| ![設定ダイアログ](docs/06-settings.png) | **設定**<br>声かけ間隔、休憩の長さ、目の大きさ・間隔、独り言、画面を消さない。 |

- 目はまばたき・視線の泳ぎ・ゆらぎ。画面をなでると指を追う。タップでウインク
- 90 分を超えると半目になる
- ときどき独り言（「水、飲んだ？」など）。設定でオフ可
- 今日の合計時間は端末に保存（localStorage）
- 黒ベタなので OLED だとほぼ消灯。眩しくない

## 使い方（スマホ）

1. 上の URL を開く
2. 「ホーム画面に追加」すると全画面・横向きで起動
3. 「はじめる」

## 開発

Vite + Preact + TypeScript。依存は Preact のみ（JS 9 KB gzip）。

```sh
npm i
npm run dev
```

| ファイル | 役割 |
|---|---|
| `src/App.tsx` | セッション状態（off / focus / break）、声かけ、Wake Lock、全画面 |
| `src/Eyes.tsx` | 目。まばたき・視線・ゆらぎ・指追い・ウインク |
| `src/Settings.tsx` | 設定ダイアログ |
| `src/lines.ts` | セリフ集。ここに足せば口数が増える |
| `src/store.ts` | localStorage（設定・今日の合計） |

## デプロイ

`main` に push → GitHub Actions が `dist` を GitHub Pages に配信。
